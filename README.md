# Portfolio Website

This is the personal portfolio website of Tan Zheng Xun, showcasing projects, experience, and contact information. Built with React, TypeScript, and Vite, and deployed on GitHub Pages.

Projects are organized into Games (engines and games) and AI (Locail). Locail has a product page at `/Portfolioweb/#/locail`, with published screenshots, feature descriptions, and downloads linked to its itch.io listing. Hash navigation allows the page to open directly on GitHub Pages without a server rewrite.

Run `npm run dev` for a local preview, `npm run build` for a production build, and `npm run lint` for lint checks.
